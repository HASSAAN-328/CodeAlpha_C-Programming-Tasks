# 📘 C++ Multi-Project: CGPA Calculator, Sudoku Solver & Banking System

## 📌 Overview

This repository contains three C++ projects combined into one complete academic and practical implementation. Each project focuses on different programming concepts such as input/output handling, data structures, object-oriented programming, and algorithms.

The projects included are:

1. CGPA Calculator
2. Sudoku Solver
3. Banking System

---

## 🎯 Objectives

* Apply core C++ concepts in real-world problems
* Practice problem solving using logic and algorithms
* Understand object-oriented programming
* Implement data handling and user interaction

---

# 🧮 Task 1: CGPA Calculator

## 📖 Description

This program calculates the GPA of a semester and overall CGPA based on user input. It takes course grades and credit hours as input and computes results accordingly.

## ⚙️ Features

* Input number of courses
* Input grade and credit hours for each course
* Calculate total credit hours
* Calculate total grade points (grade × credit hours)
* Compute GPA and CGPA
* Display all course details and final result

## 🧠 Concepts Used

* Loops
* Arrays
* Mathematical calculations
* User input/output

---

# 🔢 Task 3: Sudoku Solver

## 📖 Description

This project solves a Sudoku puzzle using a backtracking algorithm. It fills empty cells while ensuring all Sudoku rules are followed.

## ⚙️ Features

* Represent Sudoku using a 2D array
* Solve puzzle using backtracking
* Check validity for:

  * Row
  * Column
  * 3×3 subgrid
* Automatically find correct solution
* (Optional) GUI can be added for better interaction

## 🧠 Concepts Used

* Recursion
* Backtracking
* 2D arrays
* Logical constraints

---

# 🏦 Task 4: Banking System

## 📖 Description

This system simulates a basic banking environment where users can manage accounts and perform transactions.

## ⚙️ Features

* Create and manage customers
* Create bank accounts
* Deposit and withdraw money
* Transfer funds between accounts
* Maintain transaction history
* Display account details and balance

## 🧠 Concepts Used

* Classes and objects
* Encapsulation
* Vectors or arrays
* Functions and modular design
